# Grimório Hogwarts 🪄

Este es un proyecto de Android desarrollado en Kotlin que consume la API de Hogwarts (`hogwarts-api.com`).

## Características
* Búsqueda de criaturas mágicas por nombre.
* Validación de campo (mínimo 3 caracteres, sin espacios vacíos).
* Carga de imágenes con Picasso y manejo de errores (imagen por defecto).
* Uso de Corrutinas y Retrofit para peticiones asíncronas.

## Tecnologías usadas
* Kotlin
* Retrofit
* Picasso
* Corrotinas
